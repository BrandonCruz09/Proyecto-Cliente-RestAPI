1. QUE NECESITAS ANTES DE SUBIRLO A GITHUB

Cada integrante debe tener instalado:

    Git
    Go
    Docker Desktop
    Una cuenta de GitHub
    VSCode o algun editor

Verificar Git:

    git --version

Verificar Go:

    go version

Verificar Docker:

    docker --version

2. CREAR CUENTA EN GITHUB

Pasos:

    1. Entrar a https://github.com
    2. Dar clic en Sign up
    3. Crear usuario, correo y contraseña
    4. Confirmar el correo electronico
    5. Iniciar sesion


3. CREAR REPOSITORIO EN GITHUB

Pasos:

    1. Entrar a GitHub.
    2. Dar clic en el boton New.
    3. Nombre recomendado:

           proyecto-servidor-crud

    4. Elegir Public o Private.
    5. No marcar "Add a README file" si ya tienes el README local.
    6. Dar clic en Create repository.

GitHub mostrara una URL parecida a:

    https://github.com/USUARIO/proyecto-servidor-crud.git

Esa URL se usara en el comando:

    git remote add origin URL

5. SUBIR EL PROYECTO A GITHUB POR PRIMERA VEZ

Desde CMD, dentro de:

    C:\Users\baapa\Desktop\proyecto_Servidor

Ejecutar:

    git init
    git add .
    git commit -m "primer avance del proyecto"
    git branch -M main
    git remote add origin URL_DEL_REPOSITORIO
    git push -u origin main

Ejemplo real:

    git remote add origin https://github.com/miusuario/proyecto-servidor-crud.git

Explicacion de cada comando:

    git init
        Crea el repositorio Git local.

    git add .
        Prepara todos los archivos para guardarlos.

    git commit -m "primer avance del proyecto"
        Crea una version guardada del proyecto.

    git branch -M main
        Define la rama principal como main.

    git remote add origin URL_DEL_REPOSITORIO
        Conecta tu proyecto local con GitHub.

    git push -u origin main
        Sube el proyecto a GitHub.

Integrantes sugeridos:

10. COMO UNIR EL TRABAJO DE LOS INTEGRANTES

La rama principal es:

    main

Cada integrante trabaja en su rama:

    backend
    database
    frontend

Cuando terminen:

    1. Suben su rama a GitHub.
    2. En GitHub crean un Pull Request.
    3. El equipo revisa los cambios.
    4. Si todo esta bien, se hace Merge a main.

Comandos para actualizar main:

    git checkout main
    git pull origin main

Unir una rama localmente:

    git checkout main
    git merge backend
    git merge database
    git merge frontend
    git push origin main

12. COMO EJECUTAR EL PROYECTO DESDE CMD

Abrir CMD.

Entrar a la carpeta:

    cd C:\Users\baapa\Desktop\proyecto_Servidor

Levantar Docker:

    docker compose up -d --build

Ver contenedores:

    docker compose ps

Ver logs de la API:

    docker compose logs api

Ver logs de PostgreSQL:

    docker compose logs db

Apagar:

    docker compose down

Apagar y borrar datos:

    docker compose down -v


13. COMO EJECUTAR LA APP DE ESCRITORIO

Primero levantar la API:

    docker compose up -d --build

Luego ejecutar el cliente:

    cd frontend
    go run .

O compilar:

    cd frontend
    go build -o cliente-sistema.exe .
    cliente-sistema.exe

Flujo dentro de la app:

    1. Presionar Recargar.
    2. Seleccionar un empleado o cliente en la tabla.
    3. Revisar que el formulario se llene.
    4. Cambiar datos si se quiere actualizar.
    5. Presionar Guardar cambios.
    6. Para borrar, seleccionar una fila y presionar Eliminar seleccionado.

16. COMO PROBAR LA API DESDE CMD CON CURL

Listar empleados:

    curl http://localhost:8090/empleados

Buscar empleado por ID:

    curl http://localhost:8090/empleados/1

Buscar empleado por nombre:

    curl "http://localhost:8090/empleados/buscar?nombre=Juan"

Crear empleado:

    curl -X POST http://localhost:8090/empleados -H "Content-Type: application/json" -d "{\"first_name\":\"Lidia\",\"last_name\":\"Lopez\",\"birth_date\":\"10-12-20\",\"gender\":\"Femenino\",\"hire_date\":\"Inmediata\"}"

Actualizar empleado:

    curl -X PUT http://localhost:8090/empleados/1 -H "Content-Type: application/json" -d "{\"first_name\":\"Juan\",\"last_name\":\"Perez Actualizado\",\"birth_date\":\"1990-01-01\",\"gender\":\"M\",\"hire_date\":\"2020-05-15\"}"

Eliminar empleado:

    curl -X DELETE http://localhost:8090/empleados/1

Consultar titulos:

    curl http://localhost:8090/empleados/1/titulos

Consultar salarios:

    curl http://localhost:8090/empleados/1/salarios

Consultar usuario:

    curl http://localhost:8090/empleados/1/usuario

19. ERRORES COMUNES

Error: Docker no responde.

Solucion:

    Abrir Docker Desktop.
    Esperar a que diga que esta corriendo.
    Ejecutar:

        docker compose up -d --build

Error: puerto ocupado.

Solucion:

    Revisar si otra app usa el puerto 8090 o 5442.
    Apagar contenedores:

        docker compose down

Error: la base no tiene los datos nuevos.

Solucion:

    docker compose down -v
    docker compose up -d --build

Error: la app no muestra empleados.

Solucion:

    Verificar que la API responda:

        curl http://localhost:8090/empleados

    Si no responde, revisar logs:

        docker compose logs api

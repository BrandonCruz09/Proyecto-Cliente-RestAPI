1. DESCRIPCION GENERAL

Este proyecto es un sistema CRUD para administrar empleados y clientes.

CRUD significa:

    C = Create  = Crear registros
    R = Read    = Consultar registros
    U = Update  = Actualizar registros
    D = Delete  = Eliminar registros

El sistema esta formado por:

    1. Backend o servidor API en Go.
    2. Cliente de escritorio en Go.
    3. Base de datos PostgreSQL.
    4. Docker y Docker Compose.
    5. GitHub Actions para validar el proyecto.
    6. Documentacion y pruebas manuales.


2. TECNOLOGIAS USADAS

Go:

    Se usa para programar la API y la app de escritorio.

PostgreSQL:

    Se usa como base de datos relacional.

Docker:

    Se usa para ejecutar PostgreSQL y la API en contenedores.

Docker Compose:

    Se usa para levantar varios contenedores con un solo comando.

JSON:

    Se usa como formato de comunicacion entre el cliente y la API.

Git:

    Se usa para controlar versiones del codigo.

GitHub:

    Se usa para subir el proyecto a internet y colaborar entre integrantes.

GitHub Actions:

    Se usa para validar automaticamente que el backend y frontend compilen.


3. ARQUITECTURA DEL SISTEMA

El sistema funciona asi:

    Usuario
       |
       v
    Cliente de escritorio Go
       |
       | HTTP + JSON
       v
    API REST Go
       |
       | SQL
       v
    PostgreSQL

Explicacion:

    1. El usuario abre la app de escritorio.
    2. El usuario crea, busca, actualiza o elimina empleados/clientes.
    3. La app envia una peticion HTTP a la API.
    4. La API recibe la peticion y ejecuta SQL.
    5. PostgreSQL guarda o devuelve informacion.
    6. La API responde en JSON.
    7. La app muestra el resultado en pantalla.

5. EXPLICACION DE CADA CARPETA

backend/

    Contiene la API REST hecha en Go.
    Esta API recibe peticiones como GET, POST, PUT y DELETE.
    Se conecta a PostgreSQL.
    Devuelve respuestas en JSON.

frontend/

    Contiene la app de escritorio hecha en Go.
    La app muestra una ventana con tablas, formularios y botones.
    Permite interactuar con empleados y clientes.
    No se conecta directamente a PostgreSQL: se conecta a la API.

database/

    Contiene el archivo init.sql.
    Ese archivo crea las tablas de la base de datos y agrega datos de prueba.

docker/

    Contiene notas relacionadas con Docker.

.github/workflows/

    Contiene el workflow de GitHub Actions.
    Sirve para probar y compilar automaticamente el proyecto cuando se sube a GitHub.

    actualizarEmpleado
    eliminarEmpleado

    obtenerTitulos

    obtenerUsuario
    crearCliente
    obtenerClientes
    obtenerClientePorID
    actualizarCliente
    eliminarCliente
    buscarCliente

El backend escucha en:

    http://localhost:8090

El backend se conecta a PostgreSQL usando:

    DATABASE_URL

Dentro de Docker Compose se usa:

    postgres://postgres:admin123@db:5432/empresa?sslmode=disable


9. ENDPOINTS DE EMPLEADOS

Crear empleado:

    POST /empleados

Listar empleados:

    GET /empleados

Buscar empleado por ID:

    GET /empleados/{id}

Actualizar empleado:

    PUT /empleados/{id}

Eliminar empleado:

    DELETE /empleados/{id}

Buscar empleado por nombre:

    GET /empleados/buscar?nombre=texto

Consultar titulos:

    GET /empleados/{id}/titulos

Consultar salarios:

    GET /empleados/{id}/salarios

Consultar usuario:

    GET /empleados/{id}/usuario


10. ENDPOINTS DE CLIENTES

    GET /clientes/{id}

Actualizar cliente:

    PUT /clientes/{id}

Eliminar cliente:

    DELETE /clientes/{id}

11. CLIENTE DE ESCRITORIO

El cliente esta en:

    frontend/main.go

Es una aplicacion de escritorio para Windows hecha en Go usando la libreria walk.

La app tiene:

    Pestaña Empleados
    Pestaña Clientes
    Tabla/listado de registros
    Formulario de captura
    Boton Recargar
    Boton Buscar
    Boton Crear nuevo
    Boton Guardar cambios
    Boton Eliminar seleccionado
    Botones para consultar titulos, salarios y usuario
    Panel de estado y respuesta JSON

Flujo recomendado:

    1. Abrir la app.
    2. Presionar Recargar.
    3. Seleccionar una fila de la tabla.
    4. Revisar que el formulario se llene automaticamente.
    5. Editar campos si se desea actualizar.
    6. Presionar Guardar cambios.
    7. Para eliminar, seleccionar una fila y presionar Eliminar seleccionado.


12. NORMALIZACION DE DATOS

La API acepta datos mas faciles para el usuario.

Genero:

    F
    M
    Femenino
    Masculino
    Mujer
    Hombre

La API convierte:

    Femenino -> F
    Masculino -> M

Fechas:

    YYYY-MM-DD
    DD-MM-YY
    DD-MM-YYYY
    DD/MM/YY
    DD/MM/YYYY
    Hoy
    Inmediata

Ejemplo:

    10-12-20 -> 2020-12-10
    Inmediata -> fecha actual


13. DOCKER

El archivo principal es:

    docker-compose.yml

Servicios:

    db  = PostgreSQL
    api = API Go

Comando para levantar:

    docker compose up -d --build

Comando para apagar:

    docker compose down

Comando para apagar y borrar la base:

    docker compose down -v


14. PRUEBAS

Se pueden hacer pruebas de 3 formas:

    1. Desde la app de escritorio.
    2. Desde CMD con curl.
    3. Desde VSCode con pruebas.http.

La forma mas directa para revisar si la API funciona es:

    curl http://localhost:8090/empleados

Si responde una lista JSON, la API esta funcionando.
